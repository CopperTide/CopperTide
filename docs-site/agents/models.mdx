An API-mode agent runs in Shakedown's own agent loop. Each model call goes through Shakedown's gateway to the agent's provider, and Shakedown records every call in one format (OpenAI chat completions) whatever the provider. Replay, forks and compare treat all providers alike.

<Note>
CopperTide has measured Claude Code and Codex live ([Claude Code and Codex](/agents/claude-code-and-codex)). CopperTide built API-model agents, OpenRouter, self-hosted model servers, Bedrock, `http` agents and the framework adapters, and tests them against simulated servers. Live checks of those are in progress.
</Note>

## Add a key or server

You add your first key during setup, on **Get started**'s **Connect a model** step, with **OpenRouter** picked to start. Add more later in **Settings → Connections & models**, under **Add a key or server**. Both show the same form.

1. Pick the kind: **Your server**, **OpenRouter**, **OpenAI**, **Anthropic** or **Bedrock**.
2. Check the **Name**. A new key is named after its kind until you type a name. The field turns what you type into lowercase letters, digits, `-` and `_`: `OpenRouter Key` becomes `openrouter-key`. Agents name a key of kind **Your server** as `custom:<name>`.
3. Paste the key, and for **Your server** the server URL. For Bedrock, give the access key ID, the secret access key and the region.
4. Optionally give a **Model**, used by **Test**. The ready example's agent also runs on it.
5. Click **Save**.

Under **Your keys** in **Settings → Connections & models**, click **Test** on a key. Shakedown makes a one-token call and shows **Works**, or the provider's reason.

Shakedown seals each key and never shows the key again, only its last four characters. See [Model keys and security](/account/keys-and-security).

## Providers

| Provider | An agent names | Key | Default model |
|---|---|---|---|
| OpenRouter | `openrouter` (also the default) | An OpenRouter key | `deepseek/deepseek-chat-v3.1` |
| OpenAI | `openai` | An OpenAI key | None: name one |
| Anthropic | `anthropic` | An Anthropic key. The gateway translates calls to the Messages API. | None: name one |
| Amazon Bedrock | `bedrock:<region>` | AWS credentials or a Bedrock API key. The gateway translates calls to the Converse API. | None: name one |
| Your server | `custom:<name>` | Optional | None: name one |
| A local server from the environment | `local:<name>` | Optional `SHAKEDOWN_LOCAL_KEY_<NAME>` | None: name one |
| One key by name | `key:<name>` | The named key | As for the key's kind |

A server of your own is any server speaking the OpenAI chat-completions API: Ollama, vLLM, LM Studio or llama.cpp's server. On a local engine the server runs anywhere you reach. In hosted Shakedown a model server's URL must be HTTPS on a public address. Shakedown refuses private, loopback and metadata addresses when you save the key, when you test the key and before every call.

## How keys resolve

Your own keys come first. A key of kind OpenRouter, OpenAI or Anthropic replaces the environment's key for the same provider, and the newest key of a kind wins. Without a key of your own, a local engine uses the environment's key (`OPENROUTER_API_KEY`, `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`). In a shared org, another member's key serves your agent only when your agent names the key as `key:<name>`.

## Rate limits

In an API-mode agent, a model call the provider refuses with a rate limit (429) waits and tries again, up to 6 times. Each wait follows the provider's `retry-after`, else the time until its limit resets, else 1 second doubling, and is at most 30 seconds. A new OpenRouter account, for example, allows 20 requests a minute, which two agents on one model reach quickly. The run's timeline marks each rate-limited try as **Model call rate-limited (429)**. A call that still fails says how many tries it took and over how long, before the provider's message.

## Costs

| Source | What Shakedown shows |
|---|---|
| OpenRouter | The cost OpenRouter reports |
| OpenAI, Anthropic | A list-price estimate from the repository's `docs/prices.toml` for the models listed there, labelled with the price's source and date, else unknown |
| A local server | No API charge, unless you set a rate with `SHAKEDOWN_LOCAL_PRICE_<NAME>` |
| Bedrock | Unknown |

In a run driven by Shakedown's own runners, the spend limit (`max_cost_usd`, or `budget.per_run_usd` in an experiment file) stops every agent once the run's estimate passes the limit, and the run ends `budget_exceeded`, scored as the world stood.
